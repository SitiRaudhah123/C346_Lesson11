Letter List App

A React Native app for adding, editing, and deleting vowel and consonant letters.

Features

Add letters to vowel and consonant sections.

Edit or delete any existing letter.

Layouts use SafeAreaView for compatibility with modern device screens.

Navigation implemented with React Navigation.
